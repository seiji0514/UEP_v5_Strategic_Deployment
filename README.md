## 1. Overview

UEP v5.0 is a self-contained enterprise platform that integrates:

- **Production SSR backends** (ERP / CRM / SCM / CARE domains) on a unified FastAPI core
- **An automated build registry** that continuously catalogs, probes, and exports the state of every system and component in the tree
- **Governance & compliance mapping** for NIST CSF and ISO 27001 controls
- **Infrastructure autonomy** — automated database failover with durable local fallback, containerized monitoring stack, and runtime security tooling
- **Bilingual (EN/JA) operator environments** across all vertical domains

The platform is designed around a **local-first, zero-external-dependency execution model**: all workloads run on-premises without reliance on third-party SaaS control planes.

## 3. Architecture at a Glance

```text
┌─────────────────────────────────────────────────────────┐
│                  UEP v5.0 Control Plane                 │
│   Registry Dashboard · Probe Engine · Snapshot/Export   │
├─────────────────────────────────────────────────────────┤
│  Tier A Production SSR      │  Tier B Platform Modules  │
│  (ERP/CRM/SCM/CARE/Exec)    │  (Compose · top modules)  │
├─────────────────────────────────────────────────────────┤
│        Unified FastAPI Core (:8080) · React Frontend    │
├─────────────────────────────────────────────────────────┤
│  PostgreSQL (primary) → SQLite WAL (durable fallback)   │
│  Docker monitoring stack · runtime security tooling     │
└─────────────────────────────────────────────────────────┘
```

**Core stack:** Python / FastAPI · React / TypeScript · PostgreSQL + SQLite WAL fallback · Docker Compose (17-service monitoring stack) · Prometheus metric endpoints · eBPF-based runtime security (Falco)
